

### Branch Naming Conversion and Meaning

| Type      | Purpose                              |
| --------- | ------------------------------------ |
| feature/  | New feature                          |
| fix/      | Bug fix                              |
| hotfix/   | Urgent production fix                |
| refactor/ | Code improvement (no feature change) |
| chore/    | Maintenance (deps, configs)          |
| docs/     | Documentation                        |
| test/     | Adding or fixing tests               |
