Choose one

Reply with A, B or C. Its palette, type and shapes become the tokens; components follow its patterns.

Or combine

Name the parts, for example "B's palette and woven band with C's table density and command palette".

What happens next

The chosen direction is frozen into DTCG tokens with the contrast gate, then the first components ship in Storybook in both themes.

Sample data is fictional. Contrast is checked per direction against WCAG 2.2 AA in both modes.
