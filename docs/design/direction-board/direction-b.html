Kente Modern

The discipline of kente weaving — strict strips, alternating blocks, a few bold threads — rebuilt as a modernist interface where pattern is a signature, never wallpaper.

  • Kente gold
  • Woven rhythm
  • Strict grid
  • Department-coded
  • Crisp 1.5px lines

Primary action: kente gold, lettered in ink. Gold is the thread kente is known for, so it marks the single thing to do on each screen — ink type on gold holds 8.9:1 in light and 10.6:1 in dark. Forest green and oxblood stay structural: the woven band, department coding, avatar rings, the sign-in weave. Status colours sit outside the brand set (teal, blue, grey) and step in lightness so they read without hue.
